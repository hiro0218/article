# 記事構成テンプレート集

記事タイプの判定は `.claude/skills/article-writer/references/article-types.md` に従う。ここではタイプ別の見出しテンプレートだけを置く。コラム・雑記（その他）は構成自由。

## 問題解決型

トラブルシューティングや課題解決を目的とした記事。

```markdown
## 背景

（問題の提起、動機の説明、なぜこの記事を書くのか）

## 課題 / 問題 / 状況

（具体的な課題の特定、現状の問題点）

## 解決方法 / 実装

（具体的な解決策の提示）

### 基本的な実装

（最もシンプルな実装例、コード5個以上推奨）

### 応用例

（実践的な応用パターン）

### エッジケースへの対応

（特殊なケースや注意点）

## 検証 / デモ / 動作検証

（実際の動作確認。デモは CodePen / StackBlitz / GitHub リポジトリへのリンクで示す）

## 参考 / まとめ

（参考文献、結論、要点の再確認）
```

セットアップ・移行手順など手順中心の記事は、`## 課題` を `## 環境 / 前提` に置き換え、`## 検証` を省略してよい。

## 知識共有型

技術仕様や概念の説明を目的とした記事。

```markdown
## 概要

（技術や概念の要約、この記事で扱う内容）

## [技術名]とは

（技術の定義、基本的な説明）

## 記述方法 / 使い方

（具体的な使用方法、構文説明）

## デモ / 実装例

（実際の使用例、コード例）

## 参考 / まとめ

（参考文献、要点の再確認）
```

## 調査・比較型 / 設計論型

article-types.md の最小構成をそのまま見出しにする。調査・比較型: 概要、課題、評価基準、結果、考察、参考。設計論型: 概要、背景、問題、代替案、注意点、まとめ。
